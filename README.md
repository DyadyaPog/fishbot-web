# FishBot — кабинет игрока (GitHub Pages)

Статическая страница для зрителей канала: вход через Twitch, свой баланс, уровень,
инвентарь и экипировка. Отдельный репозиторий от бота: здесь только фронтенд,
бот и его локальная админка живут в другом проекте.

Сейчас это заготовка: вёрстка в стилях админки бота, гостевой экран, кнопка входа
(пока заглушка) и демо-режим с примером данных. Точки подключения Supabase помечены
`TODO(Supabase)` в `assets/app.js`.

## Структура

```
.
├── index.html                # профиль, инвентарь, экипировка, рейтинг
├── config.js                 # supabaseUrl / supabaseAnonKey / channel (пока пустые)
├── assets/
│   ├── style.css             # стили админки + дополнения кабинета
│   └── app.js                # вкладки, фильтры, экипировка, демо-данные
└── .github/workflows/pages.yml
```

## Локальный просмотр

Из корня репозитория:

```bash
npx --yes serve .
# или
python -m http.server 4173
```

Открыть `http://localhost:4173/`. Просто открыть `index.html` файлом тоже можно,
но тогда браузер не подгрузит соседние файлы (`config.js`, `assets/*`) — стили пропадут.

## Публикация

1. Создать репозиторий на GitHub (для бесплатных Pages — публичный) и запушить `main`.
2. **Settings → Pages → Source: GitHub Actions**.
3. Push в `main` запускает `.github/workflows/pages.yml`, сайт появляется на
   `https://<user>.github.io/<repo>/`.

Значения Supabase можно держать прямо в `config.js` (URL и anon key публичны при
корректном RLS) или задать repository variables `SUPABASE_URL`, `SUPABASE_ANON_KEY`,
`FISHBOT_CHANNEL` — workflow подставит их на этапе деплоя.

## Что нужно для реальных данных

- Таблицы `users`, `inventory`, `catches` в Supabase и провайдер Twitch в
  **Authentication → Providers**.
- Redirect URL страницы в **Authentication → URL Configuration**.
- RLS: игрок читает только свои строки; экипировка — через RPC с проверкой владельца.
- Замена демо-данных на запросы `supabase-js`.

## Ограничения заготовки

- Кнопки «Продать» и «Использовать» отключены — это логика бота, её пока не дублируем.
- Рейтинг и последние уловы — статические примеры.
- Вход через Twitch не выполняется: нет клиента Supabase и провайдера.
